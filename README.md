⭐ Bookmark Recipe Book

This is the mod that help you save the recipes you want to craft.

✨ Features
Can save recipes you want to craft easily in the bookmark tab.
Can remove recipes you added in the bookmark tab.

📖 How to Use
Open your Recipe book
Hover your cursor on the recipe you want to save
Press the hotkey you set in the setting
Check your Bookmark tab, it gonna be there

If you don't want to see the recipes you added, hover on it once more time and press the key you set, it will be removed from the bookmark tab.

⚙️ Compatibility
Minecraft Version: 1.21.1

Mod Loader: Fabric

Client-Side: This mod is completely client-side! You can install it on your computer and use it on vanilla multiplayer servers without the server needing to install it.
